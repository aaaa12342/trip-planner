# 旅行攻略生成器 · Trip Planner

纯静态旅行规划工作台，无需后端、注册或 API Key。先选目的地和景点，再生成包含逐站交通、推荐抵达站点和地图的每日路线。

## 快速开始

直接打开 `index.html` 可以使用。Leaflet 和 GSAP 随项目本地提供；天气、在线底图、道路路线和未收录地点查询需要网络。

Windows 推荐显式指定项目目录启动，避免打开其他项目：

```powershell
python -m http.server 8188 --bind 127.0.0.1 --directory "E:\AAA\Travelling"
```

浏览器访问 [本地预览](http://127.0.0.1:8188/)。项目移到其他路径后修改 `--directory` 参数；8188 被占用时可换空闲端口。

## 使用流程

1. 填写出发地、目的地与日期。已收录目的地立即展示景点；其他地点点击“查看推荐景点”，同名地点需确认候选。
2. 勾选想去的景点，设置出行方式、当地交通与天数。节奏和住宿偏好可展开调整，侧栏同步显示选择。
3. 点击“按所选景点生成路线”。路线逐站展示游览时长、交通衔接与地图查询链接；桌面路线和地图并排，手机依次排列。
4. 火车、高铁或飞机出行可比较推荐抵达站点并手动切换，交通、住宿、地图同步更新。
5. 在行程编辑区调整景点、日期和顺序；可保存到本机、导入/导出 JSON、复制输入链接或打印为 PDF。

已有景点列表时隐藏重复查询按钮；联网查询中可以取消，失败后可重试。全选、清空仅在有作用时显示。完整操作见 [流程与存档说明](docs/workflow.md)。

## 功能与数据

- **出行方式**：自驾、打车、火车、高铁、飞机、邮轮、大巴。
- **当地交通**：公共交通、打车、自驾、包车、租车。
- **时长与节奏**：一天一夜至六天五夜；轻松、舒适、紧凑三档。
- **每日路线**：按时间预算与距离安排所选景点，放不下的列为备选，手动超时明确提示。
- **抵达站点**：首个实际游览景点距离占 70%，全部已安排景点均距占 30%；支持手选，车次与航线需另查。
- **旅行辅助**：逐日天气、穿搭、携带物品、住宿区域、景点详情与美食。
- **本机存档**：最近 10 份攻略；JSON 保留手动行程与站点选择，单文件上限 1 MB。输入链接仅分享输入和偏好。
- **界面与动效**：三步工作台、实时摘要、响应式布局、键盘操作、GSAP 动效、减少动态效果及依赖缺失降级。

本地知识库包含 220 个城市条目、71 个独立景区目的地和 40 份城市住宿资料。其中 48 个城市有本地精选景点，共 215 个；其余城市查询附近景点后再勾选。新增城市资料见 [景点补充记录](docs/attractions.md)。

## 开发验证

页面运行无需安装 Node 依赖。规则及静态检查需要 Node.js 18 或更新版本：

```bash
node scripts/check.cjs
node --test tests/core.test.cjs tests/catalog.test.cjs tests/features.test.cjs tests/arrival.test.cjs
```

浏览器验证使用 Playwright：

```bash
npm install
npm run check
npm test
# 非 Windows 环境先运行：npx playwright install chromium
npm run test:browser
```

Windows 默认使用本机 Edge；其他系统默认使用 Playwright Chromium。可通过 `PLAYWRIGHT_BROWSER_PATH` 指定浏览器，`QA_SCREENSHOT_DIR` 指定截图目录。测试自行启停临时静态服务器，默认使用项目内 Leaflet，第三方接口和瓦片响应由测试替代。

当前基线：**36 项规则/数据测试、41 个浏览器场景、20 个应用脚本静态检查**；包含 1,746 种目的地与天数组合，以及 320/375/768/1280 像素布局和打印检查。

可选单视口在线地图检查：`node tests/live-map.cjs`。该检查仅将天气替代为失败，真实请求当前视口瓦片，不自动平移或批量预取。模拟回归不代表在线服务可用，真实检查也只反映当次本机访问。历史证据见验证记录。

## 数据与能力边界

- 使用 Open-Meteo（定位与天气）、OpenStreetMap（底图/景点）、Overpass（景点查询）和 OSRM（驾车参考路线）。在线服务可能失败或限流，界面分别提示并降级。
- 路线由本地知识库和规则生成。交通时间按距离与方式估算，住宿比较基于直线距离及区域资料，不是实时导航、酒店价格或质量评级。
- 铁路、航空与每日景点连线为顺序示意；大巴的驾车参考路线不代表班次。实际车次、航线、运营、换乘、预约和开放时间需出发前核实。
- 地理编码失败会阻止生成；天气失败仍显示其余模块；景点查询失败可重试。底图失败保留路线和标记，支持重试；不再使用需要密钥的 CARTO。
- 自动安排遵守预算，备选景点不丢失；手动调整可超预算并显示提醒。一天一夜按当天游览、住一晚、次日返程解释。
- 天气按旅行日期查询，超出预报范围时提示；恢复存档不会自动刷新天气。本机存档位于当前浏览器 localStorage，可导出备份或删除。
- 打印包含攻略文本与景点详情，省略交互地图和编辑控件。分享 `file://` 页面时请使用 JSON；远程输入链接需建立在可访问的网站地址上。
- taste 主技能面向宣传页；本项目按配套应用 redesign 流程打磨。原版检查器未全通过，未适用规则及原始结果完整保留。
